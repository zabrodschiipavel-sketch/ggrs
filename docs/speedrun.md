# CPU Training Speedrun — TinyStories-10M на ноутбучном процессоре

Протокол ставки №1 проекта (см. [project-graph.md](project-graph.md), формат вдохновлён
modded-nanogpt): фиксированная задача, фиксированные данные и метрика, одна команда,
лидерборд по wall-clock. Первая строка лидерборда — бейзлайн этого репозитория,
установлен 2026-07-20.

## Задача

Обучить GPT ~7.5M параметров (конфиг `d10m`) на TinyStories так, чтобы
**val loss ≤ 1.7764** (цель = результат бейзлайна), за минимальное wall-clock время
на эталонном CPU. Никакого GPU, никаких внешних зависимостей — только `ggrs`.

## Фиксировано протоколом

| Что | Значение |
|---|---|
| Данные | HF `roneneldan/TinyStories`: `TinyStoriesV2-GPT4-train.txt` (2 227 753 162 байт) + `TinyStoriesV2-GPT4-valid.txt` (22 502 601 байт), CDLA-Sharing-1.0 |
| Токенизатор | byte-level BPE vocab 4096, обучается детерминированно: `train_bpe <train.txt> tinystories4096.bpe 4096 16` (сэмпл 16 МиБ, ties разрешаются лексикографически) |
| Токены | `pretokenize <train.txt> <bpe> ts_train.bin /dev/null 0.0` → 494 967 388 train-токенов; `pretokenize <valid.txt> <bpe> /dev/null ts_val.bin 1.0` → 4 996 871 val-токенов |
| Модель | `GptConfig::d10m()`: vocab 4096, d 256, h 8, layers 8, t 256, d_ff 704, RoPE base 1e4, tied embeddings, RMSNorm без гаммы, без bias — 7 471 104 параметра |
| Метрика val | loss по 8 детерминированным окнам `val_windows(bin_val, t=256, n=8)` — ровно то, что печатает тренер в колонке `val_loss` |
| Эталонный CPU | AMD Ryzen 7 7730U (8 ядер / 16 потоков, AVX2+FMA, без AVX-512), Windows 11, питание от сети |
| Wall-clock | от старта процесса `train` до первого eval с val ≤ цели; чекпоинты/eval внутри прогона входят в время |
| Воспроизводимость | сид обязателен в записи; прогон обязан быть воспроизводим командой из записи бит-в-бит (движок гарантирует побитовость при любом числе потоков) |

Что МОЖНО менять: оптимизатор, LR-расписание, гиперпараметры, число потоков, порядок
данных (сид), архитектурные твики, НЕ меняющие бюджет параметров >±5% и словарь.
Что НЕЛЬЗЯ: другие данные/токенизатор/метрика, предобученные веса, GPU.

## Бэклог трюков (кандидаты на следующие строки)

В порядке ожидаемой отдачи (по исследовательской базе проекта, [research/](research/)):

1. **Muon / Polar Express** — второй оптимизатор сразу после AdamW-бейзлайна; доказан от
   124M (спидран modded-nanogpt) до 1T (MuonClip); состоит из matmul — ложится на наши
   AVX2-ядра. Запланирован как «Фаза 3.5».
2. **Untied embeddings** — стандартный трюк GPU-спидрана, +параметры, но быстрее сходимость.
3. **QK-norm** — стабильность на бόльших lr ⇒ можно поднять lr выше 6e-4.
4. **Перф-ядра Фазы 6** (фьюзы, параллель mulmat по строкам a, планировщик арены) — чистое
   ускорение tok/s, конвертируется в wall-clock 1:1.
5. **CPU-форк OpenAI Parameter Golf** — второй формат спидрана рядом с этим (16MB артефакт,
   FineWeb); отдельный протокол, когда появится время.

## Как сабмитить строку

Один прогон = одна строка: дата, рецепт (все отклонения от бейзлайна), wall-clock до цели,
val на финише, точная команда + хеш коммита ggrs. Прогон на другом CPU допустим только как
вне-зачёта (пометка), зачёт — на эталонном 7730U.
