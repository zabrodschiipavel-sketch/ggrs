# Фаза 1.5: перекладка фундамента под исследовательскую базу — Implementation Plan

> **For agentic workers:** исполняется по матрице docs/process/workforce.md: механика — deepseek-v4-flash через dev_agent.py, средние задачи — :thinking, ревью — архитектор. Чекбоксы `- [ ]` для трекинга.

**Goal:** Ядро ggrs-core готово к блочно-квантованным типам (traits как в ggml), имеет F16 как первый не-4-байтовый тип и телеметрию спидрана — без изменения поведения существующих f32-путей (все 23 теста остаются зелёными без правок их ожиданий).

**Architecture:** Порт ggml type-traits: тип описывается парой (blck_size, type_size); `nb[0] = type_size`, строка = `row_size(ne0) = ne0/blck_size*type_size`; contiguity/nbytes считаются через row_size. F16 — собственные битовые конверсии (zero deps). Телеметрия — env-гейт `GGRS_PROFILE=1`, пишет per-op wall-clock в stderr после compute.

**Tech Stack:** Rust stable gnu, zero deps (включая half — конверсии свои).

## Global Constraints

- Все существующие тесты проходят БЕЗ изменения их ассертов (кроме явно перечисленных в задачах мест, где тест проверял старую семантику nb).
- clippy --tests -- -D warnings чист.
- Для f32/i32: blck_size=1, type_size=4 → все текущие nb/страйды численно НЕ меняются (обратная совместимость гарантирована конструкцией).
- Ядра вместо `assert_eq!(t.nb[0], 4)` проверяют `assert_eq!(t.dtype, DType::F32)` + плотность строки через `t.nb[0] == t.dtype.type_size()`.
- Запрещено добавлять квант-типы (Q8_0 и пр.) — только фундамент.
- Коммит после каждой задачи; исполнитель прикладывает вывод тестов.

### Task R1a: DType traits + F16 конверсии (исполнитель: deepseek-v4-flash:thinking)

**Files:** rewrite `crates/ggrs-core/src/dtype.rs`; tests внутри модуля.

**Interfaces (Produces):**
```rust
pub enum DType { F32, F16, I32 }
impl DType {
    pub fn blck_size(self) -> usize;           // элементов в блоке: 1 для всех текущих
    pub fn type_size(self) -> usize;           // байт на блок: F32=4, F16=2, I32=4
    pub fn row_size(self, ne0: usize) -> usize; // ne0 кратно blck_size; = ne0/blck*type_size
    pub fn size(self) -> usize;                 // УДАЛИТЬ после миграции вызовов (Task R1b)
}
pub fn f32_to_f16(x: f32) -> u16;  // IEEE 754 binary16, round-to-nearest-even, с обработкой inf/nan/denormal
pub fn f16_to_f32(h: u16) -> f32;
```

Тесты (обязательные значения): `f16_to_f32(f32_to_f16(1.0))==1.0`, `f32_to_f16(0.0)==0`, roundtrip для [-2.5, 0.1, 65504.0 (max f16)], `f32_to_f16(1e20).is_infinite() после обратной конверсии`, `f16_to_f32(0x3C00)==1.0`, `f16_to_f32(0x7E00).is_nan()`, денормал: `f16_to_f32(0x0001)==2.0f32.powi(-24)`.

- [ ] Тесты → реализация → зелёно → clippy → commit `feat(core): DType traits (blck/type/row_size) и F16-конверсии`

### Task R1b: миграция tensor/context на row_size (deepseek-v4-flash:thinking; ревью строгое — это сердце)

**Files:** `tensor.rs` (`nbytes`, `is_contiguous`), `context.rs` (`new_tensor` nb-расчёт, `reshape`, `data_*`, `get_f32`), все места `dtype.size()`.

**Interfaces:** публичные сигнатуры НЕ меняются. Семантика nb для blck_size=1 — численно прежняя.

Точки правки:
```rust
// context.rs new_tensor: было ts=dtype.size(); nb=[ts, ts*ne0, ...]
let nb0 = dtype.type_size();
let nb1 = dtype.row_size(ne[0]);
let nb = [nb0, nb1, nb1 * ne[1], nb1 * ne[1] * ne[2]];
// nbytes (tensor.rs): dtype.row_size(ne[0]) * ne[1] * ne[2] * ne[3]
// is_contiguous: nb[0]==type_size && nb[1]==row_size(ne0) && nb[2]==nb[1]*ne1 && nb[3]==nb[2]*ne2 (с учётом ne==1 послаблений как сейчас)
// reshape: страйды через row_size; assert ne[0] % blck_size == 0
// data_f32/data_i32: без изменений поведения; get_f32 — как было (только F32)
```
Добавить `Context::data_u16(&self, id) -> &[u16]` и `set_f16(&mut self, id, vals: &[f32])` (конверсия в u16 при записи) — минимальный ввод/вывод F16-тензоров.

- [ ] Все 23 существующих теста зелёные без правок → новый тест: `new_tensor_2d(F16, 4, 2)` имеет nb=[2,8,16,16], nbytes=16 → commit `feat(core): страйды и размеры через type traits; F16-хранение`

### Task R1c: dtype-asserts во всех ядрах + F16-пути cont и get_rows (deepseek-v4-flash)

### Task R2: телеметрия спидрана (deepseek-v4-flash)

**Files:** `compute.rs`, `lib.rs` (`pub mod util;`), новый `util.rs`.

**Interfaces:**
```rust
// util.rs
pub struct Lcg(pub u64);
impl Lcg { pub fn new(seed: u64) -> Self; pub fn next_f32(&mut self) -> f32; /* (x>>33)/2^31 - 0.5 — как в тестах */ }
// compute.rs: если env GGRS_PROFILE=1 — после исполнения графа eprintln! таблицы:
// op, calls, total_ms, %; замер через std::time::Instant вокруг dispatch (только n_threads==1-путь замеряет per-op; в многопотоке — общий wall-clock графа)
```

`compute` не меняется по сигнатуре; профилирование — отдельная функция + env-гейт внутри `compute` (дешёвая проверка один раз). Тест: `compute_profiled` возвращает ненулевые тайминги и сумма calls == числу не-view узлов; существующий transformer_forward — эталон равенства результатов compute vs compute_profiled.

- [ ] Тесты → зелёно → clippy → commit `feat(core): телеметрия per-op (GGRS_PROFILE), pub Lcg для сидов`
